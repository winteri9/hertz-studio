# Контент и дизайн

Правила этого проекта. Общие принципы — `~/.dsh/rules/architecture.md`, они здесь не дублируются.
Открывать при любой правке текста, цвета, типографики или вёрстки.

## Тексты

- От лица клиента и к его покупателю. Спокойно, конкретно, без «премиум», «эксклюзивный сервис»,
  «индивидуальный подход», «команда профессионалов».
- Кнопка называет действие: «Записаться на показ», «Получить оценку за 24 часа». Не «Подробнее», не «Узнать больше».
- Нет факта — нет строки. Цифры, сроки, цены, отзывы не выдумываются. Источник — в шапке файла данных.
- Каждое утверждение должно выдерживать вопрос «с чего ты взял».

## Цвет

- Сырой `#hex` только в `src/styles/tokens.css`. В компоненте — `var(--…)`.
- Новый оттенок = новый токен, а не значение на месте.
- Белый текст допустим на `--accent` и `--ink`. На `--paper` — никогда.
- После смены палитры — `npm run contrast`. Пара ниже нормы правится в токене, а не подгонкой компонента.

## Типографика

- Одна шкала на проект. Кегли и трекинг — в `base.css`, не в секциях.
- Моноширинный — только для чисел, которые правда являются данными (цены, счётчики, чеки).
  Не для подписей и не «для стиля».
- Неразрывные пробелы: числа с единицами (`100 млн ₽`), короткие предлоги в конце строки.
- Крупный заголовок, который должен держать N строк, привязывается к ширине своей колонки
  (`container-type: inline-size` + `cqi`), а не к `vw`.

## Вёрстка

- Проверять 1440, 390, плюс 320 и 1920 глазами.
- Горизонтального скролла быть не должно: `scrollWidth === innerWidth`. `shot.mjs` на этом падает.
- Порядок блоков — только в `src/pages/index.astro`.
- Один блок макета = один файл в `src/components/sections/`.

## Движение

- Одна осмысленная анимация на проект. Остальное — ответ на действие (наведение, открытие, клик).
- Скрытие до анимации — только под `html.js` и только ниже первого экрана.
- `prefers-reduced-motion: reduce` отключает всё. Без JS страница читается целиком.
- Не анимировать `top` / `left` / `width` / `height`. Только `opacity`, `clip-path`, `translate`, `scale`, `rotate`.
- Бюджет: блок ≤ 2 с, сдвиги ≤ 24 px, без скролл-джекинга.

## Фото

- Только бесплатная лицензия. `plus.unsplash.com` — платная Unsplash+, брать нельзя.
- Атрибуция обязательна: автор + ссылка на Unsplash. Источник — `assets/photos/photos.json`.
- Hero и ключевые блоки — скачанные фото (`tools/fetch_photos.py`). Галереи — хотлинк с `srcSet`.
- Отбирать контакт-листом: смотреть картинки, а не описания. Подбирать под палитру проекта.

## Чего не делаем

Капс-надписи над заголовками · моноширинные лейблы · «→» в текстах ссылок · средние точки-разделители ·
одинаковый fade-up на каждой секции · карточки с тенью на всё · нумерация там, где нет последовательности ·
Google Fonts и CDN для шрифтов · сгенерированные фото, выдаваемые за реальные.
