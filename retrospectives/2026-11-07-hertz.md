# HERTZ — ретроспектива вехи

**Задача.** Собрать флагманский кейс: премиальный лендинг студии звукозаписи с архитектурой,
дизайном, сложным движением и машинными проверками.

**Как решали.**
Astro static + данные в `src/data`. Фото скачаны локально и связаны с релизами через `PhotoId`.
GSAP отвечает за маску, параллакс и появление секций; Canvas + Web Audio — за сигнал.
Микрофон включается только по клику, ошибка доступа выводится текстом. `verify` расширен
проверкой фотоманифеста.

**Было → стало.**
Пустой шаблон с TODO → 10 машинных проверок, 6 локальных фото с атрибуцией, 4 услуги,
4 релиза, 5 единиц оборудования, живой визуализатор и три состояния (JS / reduce / no-JS).

**Уроки.**
- `yPercent` в GSAP не снимает пиксельный `y`, если CSS задал процентный transform. Для маски
  надёжнее анимировать и `y`, и `yPercent`.
- Fixed-элемент внутри `overflow:hidden` лучше вынести из секции: иначе на коротком мобильном
  герое он оказывается над следующей секцией.
- Статичный Canvas в reduce нужно рисовать после `resize()`, иначе ширина нулевая.
- Полностраничный скриншот с fixed-HUD — источник артефактов; для отчёта нужен отдельный
  viewport-снимок героя.
